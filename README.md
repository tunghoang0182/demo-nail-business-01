# Nail Business 01

Clean business-tier nail website starter with a white navbar and a full-width pink hero image.

This folder is a standalone Next.js project root. Copy it into `client-projects/`,
run `npm install`, and update `content/site.ts` plus local image assets for the
client.

## Customize

- Navigation and logo text: `content/site.ts`
- Main banner image: `nail-business-01.png`
- Layout styling: `components/home-page.module.css`
- Template metadata: `template.config.ts`

`package-lock.json`, `.next/`, and `node_modules/` are intentionally not
committed in the starter.
